# StudyBot

Personal study command center for daily tasks, GATE 2027 and UPSC 2027 countdowns, study heatmaps, monthly goals and AI task commands.

## Deploy
Set VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY, OPENAI_API_KEY and OPENAI_MODEL=gpt-5-mini in Vercel. Run supabase/schema.sql in Supabase SQL Editor first.
